### Modul "Surat Tugas" — generate Word/PDF dari template, multi-pegawai (DONE, 2026-10-01)

User minta: tool baru generate Surat Tugas dari template `.docx` yang dia kasih (`contoh/1. template st.docx`), bisa menugaskan banyak pegawai sekaligus. Template asli dicek langsung (`ZipArchive` buka `word/document.xml`) — pakai 3 bentuk placeholder berbeda: `${nomor_naskah}`/`${tanggal_naskah}`/`${ttd_pengirim}` (teks `${...}` polos), `<<berdasarkan>>`/`<<hari_tanggal>>`/`<<waktu>>`/`<<tempat>>` (tag mentah `<<>>`), dan `judul`/`tempat` lewat Word **MERGEFIELD** asli (field code mail-merge, bukan teks biasa).

**Keputusan user** (beberapa putaran tanya-jawab): `nomor_naskah`/`tanggal_naskah`/`ttd_pengirim` **TIDAK diisi sama sekali** oleh tool ini — dibiarkan literal `${...}` di dokumen hasil, karena nanti diisi di aplikasi **Srikandi** saat registrasi naskah dinas resmi (tool ini cuma bikin draf ST, bukan sistem naskah dinas). 2 dasar hukum yang di template aslinya **hardcode** di teks (Perda APBD 2026 + Perwal Penjabaran APBD 2026) dipindah jadi **Setting** yang bisa diedit admin (halaman `/kepegawaian/dasar-hukum-surat-tugas`) — supaya ganti Perda/Perwal tahun berikutnya tinggal edit di situ, bukan edit file Word. Tiap generate surat, ada field tambahan opsional "Dasar Hukum Tambahan" (textarea, satu baris = satu dasar hukum) khusus surat itu saja — digabung dengan Setting baku saat digenerate. Pegawai yang ditugaskan dipilih dari `PegawaiProfil` (bukan ketik manual) via Repeater searchable Select, otomatis isi nama/jabatan/pangkat-golongan dari NIP yang dipilih. Output bisa **Word atau PDF** (dua-duanya, tombol terpisah). Setiap surat yang pernah digenerate **disimpan riwayatnya** di DB (bukan stateless) — ada halaman list, bisa lihat detail & download ulang kapan saja.

**Persiapan template** (modifikasi manual `.docx`, dilakukan sekali, tersimpan sebagai file master aplikasi — bukan upload-ganti oleh admin, karena perlu tahu struktur teknis XML-nya): dibongkar via `ZipArchive` (`word/document.xml`), lalu dengan Python:
1. Semua MERGEFIELD (`judul`, `tempat`) dikonversi ke `${judul}`/`${tempat}` teks biasa — cari pasangan `<w:fldChar w:fldCharType="begin"/>`...`end` yang mengandung `MERGEFIELD <nama>` di `w:instrText`, ganti seluruh run jadi `<w:r><w:t>${nama}</w:t></w:r>` polos.
2. `<<hari_tanggal>>`, `<<waktu>>`, `<<tempat>>` (yang kedua, di tabel info rapat — ada 2 kemunculan `tempat`, satu MERGEFIELD satu lagi `<<>>` mentah, SALAH SATU sempat kelewat di percobaan pertama, baru ketahuan & diperbaiki setelah tes dump teks penuh) dikonversi ke `${hari_tanggal}`/`${waktu}`/`${tempat}`.
3. Baris tabel lampiran pegawai (`<w:tr>` berisi "Riyanto Nugroho" contoh) diubah isinya jadi `${no}.` / `${nama}` + `<w:br/>` + `${nip}` / `${jabatan}` / `${pangkat_golongan}` — dipakai `TemplateProcessor::cloneRow('no', N)` dari PHPWord utk clone sebanyak pegawai yang dipilih, lalu `setValue("field#N", ...)` per baris.
4. 2 dasar hukum hardcode + placeholder `<<berdasarkan>>` tambahan DIHAPUS SEMUA, diganti satu block `${dasar_hukum}` ... `${isi_dasar_hukum}` ... `${/dasar_hukum}` (pola `cloneBlock()` PHPWord) — supaya SEMUA dasar hukum (baku dari Setting + tambahan per-surat) seragam lewat satu mekanisme clone, bukan sebagian hardcode sebagian dinamis.
- Hasil akhir disimpan di `resources/templates/kepegawaian/surat-tugas.docx` (folder baru, bukan `storage/` — template ini bagian dari kode aplikasi, bukan data pengguna).
- **Diverifikasi ekstensif** sebelum dipakai fitur sungguhan: `TemplateProcessor::getVariables()` cek semua 15 placeholder kedetek benar; `cloneBlock('dasar_hukum', 0, true, false, [])` (0 dasar hukum tambahan) dicek TIDAK menyisakan paragraf kosong; `cloneBlock(..., N, ..., $arr)` dengan replacement array (bukan `indexVariables=true` — sempat salah pakai kombinasi yang menyisakan placeholder `#1`/`#2` ter-literal, diperbaiki jadi `indexVariables=false` + `variableReplacements` eksplisit) dicek 1/2/3 baris dasar hukum tambahan render benar; `cloneRow('no', N)` dicek 1/2/3 pegawai; render ke PDF sungguhan (`IOFactory::createWriter($phpWord, 'PDF')`, `Settings::setPdfRendererName(PDF_RENDERER_DOMPDF)`) dicek via `pdftotext` — semua teks utuh, layout rapi, placeholder Srikandi tetap literal `${nomor_naskah}` dkk di output akhir.
